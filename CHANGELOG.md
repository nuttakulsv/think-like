# Changelog

## 0.1.0 - 2026-10-03

First release.

- 23 minds as skills, in four groups: understand and debug (Feynman, Pólya, Ohno, Shannon), correctness and design (Dijkstra, Liskov, Ousterhout, Hickey, Knuth, Einstein, Tesla), build and ship (Beck, Fowler, Torvalds, Carmack, Brooks), and decide (Musk, Bezos, Munger, Kahneman, Turing, Socrates, Hopper).
- `council`: 3–5 minds review one decision, with a synthesis that names the disagreements and a recommendation.
- `mind-maker`: drafts a new mind skill from your sources, with a consent check for living people.
- `minds`: index of the pack and which mind to use when.
- Claude Code plugin marketplace manifest, so the pack installs with `/plugin marketplace add nuttakulsv/think-like`.
- `scripts/validate.mjs`, run in CI, and four longer example sessions in `examples/`.
